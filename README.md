## Abstract

This research proposes a deep learning–based framework for enterprise financial performance evaluation using convolutional neural networks (CNNs).

The study uses financial data from 144 listed companies over a five-year period and constructs a comprehensive financial evaluation indicator system containing 36 financial indicators. Multiple financial performance evaluation methods are combined, including:

- TOPSIS
- Grey Relational Analysis (GRA)
- Fuzzy Comprehensive Evaluation (FCE)
- CRITIC weighting
- Entropy weighting
- SOM clustering
- Convolutional Neural Networks (CNN)

The framework first computes enterprise financial performance scores using traditional financial evaluation methods and objective weighting techniques. Self-Organizing Maps (SOM) are then used to generate clustering labels for supervised CNN training.

Experimental results demonstrate that the proposed GRA-Entropy-SOM-CNN model achieves superior classification performance, reaching a maximum accuracy of 97.18%, outperforming traditional SVM-based approaches.

---

## Research Contributions

- Constructed a hybrid financial evaluation framework integrating statistical weighting methods and deep learning.
- Designed a CNN-based enterprise financial performance classification model.
- Compared CRITIC and Entropy weighting strategies.
- Evaluated multiple financial evaluation pipelines:
  - TOPSIS-Entropy-SOM-CNN
  - GRA-Entropy-SOM-CNN
  - FCE-Entropy-SOM-CNN
- Demonstrated CNN superiority over SVM for financial performance classification tasks.
